# 分析资料与解释边界

## 设计资料
classes 的 lecture 为整班随机组件；assignments 的 practice 为班内分配组件。班级属于 block，分配概率在 allocation_plan 中给出；observed_at 与 analysis_cutoff 决定可用结果。outcomes 按 learner 唯一，重复提交相同值不增加样本量，冲突不静默择优。result 是前后测变化而非原始分数。
## 产品延伸
用户对比可以引用单组件水平和组合均值。需要区分观测均值、设计所支持的目标对比和不可估对比；允许开发者选择设计与推断方法，并解释适用条件。没有整班复制的组件不能依靠班内人数制造可靠推断。现有原始对比属于描述性结果，不能改名后充当新分析。
## 可复核边界
完整平衡的二乘二资料应与手算四格均值对比一致；删除整格会使某些而非所有对比不可估。复制同一学生记录不应改变结果；同班相关性、嵌套 block 和随机化层级要在独立构造的检验中体现。analysis_cases 包含完整设计、缺格和整班无复制情形，结论方向不预设。
